# Specialisterne — Wireframe (web global)

Wireframe HTML de la web global de Specialisterne (proyecto Zoopa).

## Estructura (rama `feedback-oct2026` — fuente editable)
- **`index.html`** + carpeta **`assets/`** (imágenes, vídeo y logos como ficheros aparte). Esta es la versión **editable** y la que sirve GitHub Pages.
- Para verlo en local hace falta un pequeño servidor estático (porque las imágenes son ficheros); o abrir el fichero autocontenido que se genera para enviar por separado.

## Ramas
- **`master`** = versión publicada / enlace en vivo (GitHub Pages): https://zoopa-smart-agency.github.io/specialisterne-wireframe/
- **`feedback-oct2026`** = trabajo del feedback de octubre 2026 (en curso). Cuando se valide, se hace merge a `master` y el enlace en vivo se actualiza.

## Feedback octubre 2026 aplicado (ZOOPA)
Contact limpio · About (vídeo oculto, frase Thorkil pendiente, estructura 12 CEOs) · FAQ en 2 pestañas con contenido real · contenidos solo-locales fuera de la global (plantillas hub) · menú Choose location · header en una línea.
